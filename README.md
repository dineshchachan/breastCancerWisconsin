# Breast Cancer Classification - ML Assignment 2

## a. Problem statement
Compare five classification algorithms for predicting whether a breast tumor is benign or malignant using Kaggles Breast Cancer Wisconsin (Diagnostic) Data Set

## b. Dataset description
Source: UCI Breast Cancer Wisconsin (Diagnostic) available on Kaggle. The dataset has 569 rows, 30 numerical features, and no missing values. The label is recoded to 0 = benign, 1 = malignant. Training dataset contains 455 data whereas testing dataset contains 114 data. 

## c. GitHub Repository Link
https://github.com/dineshchachan/breastCancerWisconsin

## d. Models used and comparison
Five classifiers: Logistic Regression, Decision Tree, KNN, Gaussian Naive Bayes and SVM.

### Observations about model performance

| ML Model Name | Observation about model performance                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
|---|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Logistic Regression | Logistic Regression performed very well on the Breast Cancer dataset, with an accuracy of 96.49% and an F1 score of 95.12%. This shows that the model was very good at distinguishing between malignant and benign tumors. This also means the model made very few incorrect malignant predictions, although it missed a small number of actual malignant cases. Overall, Logistic Regression gave good results across all the evaluation metrics. |
| Decision Tree | The Decision Tree achieved an accuracy of 92.11% and an F1 score of 88.61%. Its performance was lower than the other four models on most of the evaluation metrics. This means that although most of its malignant predictions were correct, it failed to identify more actual malignant cases compared to other models                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| KNN | KNN achieved an accuracy of 95.61% and an F1 score of 93.83%. Its performance was slightly below Logistic Regression and SVM, but it still produced good results.  KNN makes predictions by comparing a new data point with nearby training samples. Since the features in this dataset have different numerical ranges, feature scaling is important for getting good results.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| Naive Bayes | Gaussian Naive Bayes achieved an accuracy of 93.86% and an F1 score of 90.91%. Naive Bayes assumes that the input features are independent of each other for a given class but this is not the case in this dataset. Overall, Naive Bayes gave reasonable results, but its lower recall is a concern because missing a malignant case is more serious than incorrectly identifying a benign case as malignant.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| Support Vector Machine | SVM gave the best overall performance among the five models tested. It achieved the highest accuracy of 97.37%, an F1 score of 96.30%, and an MCC score of 94.42%.The precision was 100%, while the recall was 92.86%. SVM tries to find a decision boundary that separates the two classes. In this experiment, the RBF kernel worked well for the Breast Cancer dataset. Based on these results, SVM was the best-performing model in this experiment..                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
